# Contributing to Awesome Ethereum Development

Thank you for your interest in contributing to this curated list of Ethereum development resources!

## Inclusion Criteria

To maintain quality and usefulness, all submissions must meet these requirements:

1. **Actively Maintained**: The project should have had activity (commits, releases, or meaningful updates) within the last 6 months
2. **Genuinely Useful**: The resource should provide clear value to Ethereum developers
3. **Primary Source**: Link directly to the project's official repository or documentation, not third-party articles or aggregators
4. **No Commercial Bias**: No paid or affiliate promotions and no token promotions. Commercial products may be listed only when they are open source

## How to Contribute

1. **Search existing items** to avoid duplicates
2. **Use the existing format**: `[Name](url) - Short, clear description`
3. **Place in the right section** and maintain alphabetical order within that section
4. **Write a descriptive commit message** explaining why the resource is valuable
5. **Keep descriptions concise** - one line that clearly explains what the tool/resource does

## Style Guidelines

- Use title case for project names
- Keep descriptions objective and factual
- No marketing language or superlatives
- Link to `github.com` repositories or official docs, not personal blogs
- Verify all links work before submitting

## Pull Request Process

1. Fork the repository
2. Create a branch for your changes
3. Make your additions following the guidelines above
4. Ensure the CI checks pass (awesome-lint and link checker)
5. Submit a pull request with a clear description of what you're adding and why

## Questions?

Open an issue if you're unsure whether a resource meets the inclusion criteria.
